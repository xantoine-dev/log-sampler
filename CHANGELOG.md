# Changelog

All notable changes to this project will be documented in this file.

The format roughly follows [Keep a Changelog](https://keepachangelog.com/) and the project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2025-02-14
### Added
- Initial release of the streaming log summarization CLI, including baseline vs. streaming strategies, memoization cache, and benchmarking helpers.
- Synthetic log generator (`benchmarks/generate_sample_log.py`) and convenience benchmark runner (`benchmark.py`).
- Documentation describing usage, benchmarking results, and development instructions.
